# human-machine

## Concept

basement.studio's HUMAN | MACHINE idea applied to a protocol. The Human rendering is a dark aubergine lander in which the
icon's bat and moon are drawn live as ordered-dithered ASCII; the moon is set in the hex digits of `moon-bat.jpg`'s real
BLAKE3 digest, so the picture is made of its own catalog data (Bakers' "media becomes data"). The Machine rendering
swaps the whole page for a plain monospace document generated from the same DOM, plus the contract's real names; the
same text ships as `llms.txt`.

"Vamp" as in jazz is structural, not decorative:

- **The figure.** The field loops one 4-beat bar at 92 BPM, quantised to eighth-of-a-beat steps: 1 the moon swells,
  2 a ring leaves the rim (the hi-hat on 2), 3 the wings lift, 4 a second ring and the wings settle. The Bayer matrix
  shifts every beat, so the texture re-voices like a comping hand. The hero's BAR/beat counter and the four
  columns of section 01 run on the same clock.
- **01 Four beats, on repeat.** The protocol as one bar between repeat signs: asset, revision, event, observation,
  each with a real JSON fragment from the session or schema.
- **02 One take, no overdubs.** A terminal replays a true `vamp` session (steps beside a terminal, after xmcp). It
  loops back to the top when it ends.
- **03 18 roots. Read the chart.** Schema explorer over the real schema roots, with excerpts cut from the bundle.
- **04 Trading fours.** Agents and the owner as call and response: exploration ensure/add (with provenance), the
  owner's rating, `explore feedback` reading it back, then the cue to go round again.
- Footer: Vampire as one line, then `D.C.` (da capo) back to the top.

## Files

- `index.html`, `styles.css`, `app.js`: page, toggle, terminal replay, schema explorer, Machine view.
- `field.js`: the dither/ASCII renderer (canvas + a pure `ascii()` used for the Machine banner and `llms.txt`).
- `bat-mask.js`: the bat silhouette traced from `shared/app-icon-1024.png` (1-bit, 312x120).
- `data.js`: generated by `python3 gen-data.py` from the schema bundle (`cargo run -p vamp-protocol --example
  schema`), `contract.json` and `vamp commands`. Rerun when the contract changes.
- `llms.txt`: generated by calling `window.VampMachine.llms()` on the page; the Machine view is `VampMachine.text()`.
- `session.log`: the raw recorded session the terminal and agents section are cut from.
- `fonts/`: self-hosted OFL fonts with their licences. `assets/vampire-icon-128.png`: the icon, once.

Works from `file://` and any static server. No dependencies, no CDNs.

## Truth notes

- Session recorded 15 Oct 2026 with `vamp 0.1.0`, `VAMP_HOME=/tmp/vamp-lander` (scratch), cwd `/tmp/refs`. Output is
  pretty-printed and shortened with `…`; values are unchanged. `[exit 1]` is the shell's exit status, shown dim.
- The owner's turn in "Trading fours" was played from the scratch CLI with no `VAMP_ACTOR`, so its actor is `local`;
  the page says so. From the app it would be `tailnet:<login>/<host>`.
- The page says the CLI ships with Vampire and the protocol is MIT; it claims no packages, public repos, users or
  benchmarks. "Source and packages: soon".
- "18 roots" is the number of top-level keys `vamp schema` prints (they include `contract` and `protocol_version`);
  the protocol README counts "15 generated schema roots plus the semantic contract". Reconcile before launch.

## Type and colour

- Display: **Archivo** variable (OFL), 112-125% width, 800-900 weight. Hero sentence in sentence case at 112%;
  section heads in caps at 125%/900.
- Mono: **Geist Mono** variable (OFL), for UI labels, code, the terminal and the canvas glyphs.
- Pixel: **Departure Mono** (OFL), for counters, beat numerals and the machine nouns inside headlines, on its 11 px
  grid (11/22/33/44/88 px).
- Colour, from the icon: ground `#08040f` / `#0d0614`, aubergine `#290922` `#3f0d28` `#59142d`, coral `#ef514f`,
  crimson `#ce2b39`, ink `#000`, plus one paper `#f3e8e3` and a muted `#b89ea8` for body text (8.2:1 on ground;
  coral 5.8:1).

## Motion and performance

- Canvas glyphs are pre-rendered once into an atlas per size; each step blits only the lit cells (about 10-16k
  cells at 1440 px, 12 redraws per second). The field pauses offscreen (IntersectionObserver), in a hidden tab and in
  the Machine view; the beat clock runs only while the hero or the four-beat bar is visible.
- First paint resolves through square blocks (basement's pixel-block loader) over 1.1 s.
- `prefers-reduced-motion: reduce`: one static frame, the counter reads `still`, the event tape stops, and the
  terminal shows the whole session at once.
